Projects & Skills

A few things I've learned and built so far in this course:

Semantic HTML Student Page

Rebuilt my first one-page HTML file into a properly structured site using header, nav, main, section and footer elements.

I learned the difference between purely visual markup and semantic markup, why heading levels matter, and how to link navigation to section ids.

Responsive CSS Layout

Styled this site with external CSS, including a photo gallery and a media query for narrow screens.

I practiced the CSS box model (padding, margin, border), class vs id vs element selectors, and writing a media query so the layout works on a phone-sized screen.

Interactive JavaScript Features

Added JavaScript: form validation, a gallery viewer, and expandable project details like the one you're reading now.

I learned how to listen for DOM events, update the page without reloading using event.preventDefault(), and validate user input with JavaScript.
